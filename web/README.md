## Локальный запуск

### Подготовка к запуску:

1. Заполнить `.env` по шаблону из `.env.example`<br>
2. Сгенерировать ссылки на файл окружения, через `./env-local.sh` (если не линукс то сорян, ручками перекопировать в _/backend_ и _/frontend_ )

### Локальный запуск бекенда

#### 1. Подготовка к запуску:

0. Важно: пакетный менеджер только `yarn`<br>
1. Установить зависимости `yarn install`<br>
2. Запушить схему в БД (БД _<POSTGRES_DB>_ предварительно должна быть создана, есесно) `yarn db:push`<br>

#### 2. Запуск:

1. Запустить бекенд `yarn start:dev`

## Боевой запуск

### Подготовка к запуску:

1. Заполнить `.env` по шаблону из `.env.example`<br>
2. Выполнить `cp .env backend/.env` и `cp .env frontend/.env`<br>
3. Заполнить `nginx.conf` по шаблону из `nginx.conf.example`<br>
4. Сгенерировать сайт-мапу `cd frontend && yarn sitemap`<br>

### Запуск:

1. Выполнить `./start.sh`
